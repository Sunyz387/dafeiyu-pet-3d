# 大肥鱼桌宠 3D 版 🐋

<p align="center"><img src="docs/preview.gif" alt="大肥鱼 3D 形象预览：眨眼、转身一整圈、眯眼笑着跳一下"></p>

> 本仓库基于 [1190fasheqi/dafeiyu-pet](https://github.com/1190fasheqi/dafeiyu-pet)（MIT）修改。
> 在原项目基础上新增：由三视图扩展的 **3D 形象**（会转身、眨眼、看鼠标、睡午觉）、灵动小动作、
> **小游戏**（接小鱼干 / 丢球 / 捉迷藏 / 吹泡泡）与**舞蹈秀**，以及一轮省资源和稳定性优化。
> 原项目的作者与贡献者见文末「贡献与致谢」。

DeepSeek V4 Pro 二创形象「鲸鱼娘·大肥鱼」的透明桌面宠物。

基于三视图素材（正面 / 侧面 / 背面），用 Python + PySide6 实现，无边框透明置顶窗口。

## 下载即用（Windows）

不想装 Python 的话，到 [Releases](https://github.com/Sunyz387/dafeiyu-pet-3d/releases/latest) 下载 `dafeiyu-pet-3d-…-windows-x64.zip`，解压到一个单独的文件夹，双击里面的 `大肥鱼桌宠.exe` 就行。

- 第一次运行如果弹出「Windows 已保护你的电脑」：点「更多信息 → 仍要运行」（exe 没有数字签名，PyInstaller 打包的程序常被误报）
- 配置、养成存档、聊天记录都存在 exe 所在的文件夹里；以后升级用新 exe 覆盖旧的就行，存档不丢
- AI 对话要用你自己的 DeepSeek API Key：右键她 →「设置」→「设置 DeepSeek Key…」

## 功能

- **三视图行走**：左右走用侧面（自动镜像）、向上走用背面、向下走用正面

- **三种模式**：自由散步 / 跟随鼠标 / 原地待着（右键菜单切换）

- **互动**：
  - 左键按住：拖拽（会侧身朝向拖动方向，松手会说话）
  - 单击：蹦跳 + 回嘴（互动台词）+ 弹出 🗨️ 聊天面板
  - 双击：喂食面板（小鱼干 / 蛋糕 / 棒棒糖 / 团子 / 钻石）
  - 右键：完整菜单（模式 / 大小 / 喂食 / 说句话 / 显示/隐藏 / 鼠标穿透 / 置顶 / 开机自启 / 退出；托盘右键是同款菜单，穿透后可从托盘解除）

- **台词系统**：日常随机台词 + 互动回嘴 + 思维链心声（灰色斜体括号气泡，小概率冒出），全部取材自社区 DS 梗

- **细节**：呼吸 / 摇摆 / 蹦跳 / 进食动画、转向交叉淡化、加减速惯性、散步自动休息、说话冷却

- 托盘图标、窗口置顶、鼠标穿透、开机自启、配置记忆（config.json）；穿透 / 置顶状态重启后自动恢复

- ##### AI 对话（新增）

  - 左键单击弹出 🗨️ 图标，点击后弹出聊天输入框
  - 调用 DeepSeek API（`deepseek-chat` 模型），每句话不超过 25 字，风格贱兮兮但可爱
  - 对话历史保留最近 40 条（自动记忆上下文）
  - API Key 通过右键菜单「设置 Key」输入，保存到 `config.json`
  - 聊天期间鱼会暂停移动，但呼吸/摇摆/小动作照常

  ##### 天气查询（新增）

  - 右键菜单「查看天气」→ 调用 `wttr.in` 获取当前城市天气
  - 城市默认从 `config.json` 读取，可手动修改配置文件中的 `"city"` 字段
  - 鱼会气泡播报：「汕头今天 26°，天气多云」

  ##### 系统状态监控（新增）

  - **CPU**：超过 90% 时冒泡提醒
  - **内存**：超过 95% 时冒泡提醒
  - **显卡（NVIDIA）**：温度超过 80°C 时冒泡提醒（`pynvml` 读取）
  - 检测间隔 10 秒，不频繁打扰

- ##### 3D 形象（新增，由原三视图扩展）

  - 用正面 / 侧面 / 背面三张原画重建出 Q 版手办体积，**转身是真 3D 旋转**：左右换方向时会先转过来看你一眼再转过去；0° / 90° / 180° 和原画逐像素一致
  - **灵动小动作**：待机时头发飘、尾巴拍、呆毛弹、耳鳍扇；走路双脚交替迈步；随机眨眼（偶尔连眨两下）
  - **看向鼠标**：鼠标在附近晃，她会侧过身看过去；鼠标停太久她就不看了，偶尔自己左右张望
  - **表情**：被摸、被投喂、伸懒腰时眯眼笑；可爱 / 性感装饰（腮红、头顶爱心）跟着 3D 头部一起转
  - 被拎起来像钟摆一样晃；被扔出去在空中转圈，落地压扁再弹回，摔重了头顶冒小星星
  - 右键「形象 → 3D 形象」可切回 2D 立绘；3D 帧缺失时自动退回 2D
  - **省资源**：所有 3D 画面都是离线预渲染好的图，运行时只贴图；空闲时降帧（待机约 17 帧、走路 25 帧、睡觉 12.5 帧），实测待机单核占用约 1%–5%，内存约 90 MB

- ##### 新玩法（新增）

  - **摸摸头**：不用点，鼠标在她头上来回划几下就是摸头——眯眼笑、冒小心心、加好感（也算每日摸头任务）
  - **肚皮朝天睡午觉**：你 6 分钟没碰电脑（深夜 3 分钟）她就躺平睡觉，冒 Zzz；你回来后她会再赖一会儿床才醒，点她立刻叫醒（会抱怨）。右键「哄她睡一觉」随时让她睡 3 分钟
  - 右键「小游戏 / 一起玩」：
    - 🐟 **接小鱼干**：鼠标左右移动带她跑，接住掉下来的小鱼干 / 虾 / 寿司 / 钻石，躲开「服务器繁忙」和 bug；45 秒一局，按分数奖励小鱼干，记录最高分
    - ⚽ **丢球给她捡**：按住球甩出去，她跑过去叼起来送回你鼠标旁边，再乖乖等你下一次扔
    - 🙈 **捉迷藏**：她数到三躲到屏幕边缘外，只探出小半个身子，30 秒内点到她就有奖励
    - 🫧 **吹泡泡**：她吹一串泡泡往上飘，点破有经验，金泡泡给小鱼干（待机时偶尔也会自己吹）
  - 💃 **性感舞蹈秀**（右键「互动」/ Ctrl+Alt+D / 聊天里叫她跳舞）：约 20 秒的编舞——扭胯摇摆、3D 转圈、单眼 wink、甩头发、回眸、弹跳、比心、定格谢幕；**在节拍上点她 = 打拍子**，判定完美 / 不错，有连击，结束按跟拍成绩给好感、经验、小鱼干
  - 更多小反应：点她的尾巴会转过身去看尾巴；点头眯眼笑；离开 5 分钟以上回来她会蹦一下欢迎你；走路起步前倾、刹车后仰；睡觉时有“啪叽”倒下和爬起来的过程
  - 新成就：肚皮朝天、接鱼达人、捡球小能手、火眼金睛、泡泡杀手、舞台搭档

- ##### 省资源 / 更稳（新增）

  - 不再装全局鼠标、键盘钩子（以前用 pynput，全系统每次鼠标移动都要进一趟 Python）：热键改用系统 RegisterHotKey，“点聊天框外面收起”改为监听程序失去激活
  - 全屏游戏 / 全屏视频时自动躲起来（不挡画面、不占 CPU），退出全屏自动回来；手动隐藏时定时器降到每秒 10 次
  - 语音关闭时不加载系统语音引擎；查天气改到后台线程（以前网络慢会卡住整只桌宠）；聊天时只有像是在叫她做动作才额外调用一次动作识别（以前每句都多调一次 API）
  - 配置 / 养成 / 聊天记录原子写入，设置一改就保存，关机注销前也会保存；只允许运行一只（重复启动会叫已经在跑的那只出来）；报错记录在 `pet.log`
  - 小鱼干上限从 20 提到 99；右键菜单按「互动 / 养成 / 设置 / 工具」分组，补上了「设置城市」

## 运行

需要 **Python 3.11+**

```bash
pip install -r requirements.txt
# 或
pip install PySide6
```

然后双击 `启动桌宠.bat`，或：

```bash
python 桌宠.py
```

## 打包成独立 exe（可分享给朋友）

```bash
pip install pyinstaller
pyinstaller --noconfirm 桌宠.spec
```

产物在 `dist/大肥鱼桌宠.exe`，对方双击即用，无需安装 Python。
（杀毒软件可能对 PyInstaller 产物误报，加信任即可。）

## 更换形象

把新的三视图（白底）放到程序目录：

1. 正面.png / 侧面.png / 背面.png（原图）
2. 运行 `python preprocess.py` —— 白底抠图 + 统一高度
3. 运行 `python preprocess2.py` —— 边缘去污 + 预乘 alpha 缩放出各尺寸精灵
4. 重新生成 3D 形象（约 1–2 分钟，只在换形象时需要）：

   ```bash
   pip install numpy pillow
   python tools/build_3d.py            # 加 --preview 会多输出一张总览图
   ```

   换了新角色时，要按新原画改 `tools/build_3d.py` 里的部件坐标：`PARTS`（呆毛、耳鳍）、`EYES`（眨眼位置）、`TAIL_* / FOOT_S`（尾巴、脚），坐标都是 340 高原画上的像素位置

## 文件说明

| 文件 | 说明 |
|------|------|
| 桌宠.py | 主程序（全部逻辑） |
| pet3d.py | 3D 形象运行时：加载预渲染帧，按朝向 / 动作挑帧 |
| games.py | 小游戏和小玩具：接小鱼干、丢球、捉迷藏、吹泡泡、性感舞蹈秀 |
| tools/build_3d.py | 3D 形象离线生成器（三视图 → 体积 → 浮雕转身 + Live2D 式形变） |
| preprocess.py | 白底三视图抠图脚本 |
| preprocess2.py | 精灵边缘去污 + 多尺寸生成脚本 |
| sprites/ | 精灵图（正面/侧面/背面 各尺寸 + 图标） |
| sprites3d/ | 3D 形象预渲染帧（转身 / 待机 / 走路 / 眨眼 / 睡觉）+ meta.json |
| docs/preview.gif | README 顶部的预览动图（用桌宠自己的绘制代码离屏渲染） |
| 启动桌宠.bat | 启动脚本（自动选择 venv 或系统 Python） |
| requirements.txt | 依赖 |
| 桌宠.spec | PyInstaller 打包配置（含新依赖收集） |
